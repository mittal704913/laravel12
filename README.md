# Laravel 12 First Project

This is my first Laravel 12 project. It is an admin panel application built for learning and practice purposes.

## Features
- User authentication (Login / Logout)
- Admin dashboard
- Basic CRUD operations
- MySQL database integration

## Tech Stack
- Laravel 12
- PHP
- MySQL
- Bootstrap

## Purpose
This project is created to practice Laravel backend development and understand real-world web application structure.

## How to Run
1. Clone the repository
2. Run composer install
3. Copy .env file and configure database
4. Run php artisan migrate
5. Run php artisan serve
