# Laravel 12 First Project

A modern admin application built using Laravel 12, Inertia.js, and React. This project is designed for learning and practicing full-stack web development.

---

## 🚀 Features

- Authentication system (Login / Logout)
- Admin dashboard
- User management system
- Responsive UI with React
- RESTful backend structure

---

## 🧰 Tech Stack

- Laravel 12
- Inertia.js
- React.js
- PHP
- MySQL
- Vite

---

## ⚙️ Setup Instructions

- Clone the repository  
- Install backend dependencies: composer install  
- Copy environment file: cp .env.example .env  
- Generate app key: php artisan key:generate  
- Run migrations: php artisan migrate  
- Install frontend dependencies: npm install  
- Run frontend: npm run dev  
- Start server: php artisan serve  

---

## 🏗️ Production Build

- npm run build  
- php artisan config:cache  
- php artisan route:cache  
- php artisan view:cache  

---

## 🛠️ Useful Commands

- php artisan route:list  
- php artisan queue:work  
- php artisan migrate:fresh  

---

This project was built for learning Laravel 12, Inertia.js, and React by developing a real-world admin panel.
